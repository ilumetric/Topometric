# Models

Sample models for 3D previews, loaded only when picked.

## stanford-bunny.glb

The Stanford Bunny, from the [Stanford 3D Scanning Repository](https://graphics.stanford.edu/data/3Dscanrep/),
Stanford University Computer Graphics Laboratory. Based on `bunny/reconstruction/bun_zipper_res2.ply`,
reduced in Blender to 3,237 vertices and 6,470 triangles.

The repository allows free redistribution with credit to the source; commercial use needs permission from Stanford.

## blender-suzanne.glb

Suzanne, the monkey head mesh built into [Blender](https://www.blender.org) (Blender Foundation),
exported from Blender: 8,153 vertices, 15,744 triangles.
